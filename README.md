# Fluency · immersa academy

Página del programa **Fluency** by teacher Isa. Sitio estático (HTML + imágenes), listo para GitHub Pages.

## Publicar en GitHub Pages

1. En github.com → **New repository**. Nombre sugerido: `fluency`. Público → **Create repository**.
2. En el repo: **Add file → Upload files**. Arrastra `index.html`, `README.md` y la carpeta `img` completa → **Commit changes**.
3. **Settings → Pages** → *Deploy from a branch* → rama `main`, carpeta `/ (root)` → **Save**.
4. En 1–2 minutos queda en `https://TU-USUARIO.github.io/fluency/`.
